# LocalFirst Knowledge Base (LFKB)
![Built for the Google Chrome Built-in AI Challenge 2025](https://img.shields.io/badge/Chrome_AI_Challenge-2025-blue?style=for-the-badge&logo=googlechrome)

A privacy-first, on-device "second brain" powered by Chrome's built-in Gemini Nano AI. All your data stays 100% local, always.

Demo: https://www.youtube.com/watch?v=Eu--HkO8tRM

---

## The Problem

People are drowning in information. We read dozens of articles, blogs, and documents every day, but this knowledge is fragmented. Traditional bookmarking is a "data graveyard," and modern cloud-based AI assistants require users to send all their private reading data to a server, creating a massive privacy risk.

## The Solution: A Private, Intelligent "Second Brain"

LocalFirst KB is a Chrome extension that transforms your browser into an intelligent, private knowledge base. It leverages Chrome's built-in Gemini Nano APIs to save, summarize, and connect your knowledge—all 100% on your device.

* **100% Local:** No cloud sync. No subscriptions. No data collection, ever. All your articles, notes, and the AI models themselves run and are stored locally.
* **Intelligent:** Go beyond bookmarks. LFKB uses AI to summarize content, find conceptual connections, and let you chat directly with your saved data.
* **Fast & Efficient:** All operations run on-device, making search and summarization nearly instant.

## APIs Used

This project is built directly on Chrome's built-in AI models:

1.  **Summarizer API:** Used to automatically generate high-quality, on-device summaries for every article you save.
2.  **LanguageModel (Prompt API):** This is the core engine for all advanced features, including:
    * **Chat with Your Knowledge:** A conversational chat bot grounded in your saved articles.
    * **Multi-Article Insights:** Synthesizing novel connections between multiple selected articles.
    * **Note Rephrasing:** Polishing your personal notes for clarity and style.

## Key Features

* **Save & Auto-Summarize:** Save any webpage with a single keyboard shortcut (`Ctrl+Shift+S`) or via the context menu. The content is immediately scraped and a high-quality summary is generated by the on-device Summarizer API.

* **Hybrid Vector Search:** A search bar that thinks in concepts, not just keywords. On every save, the extension creates a BM25 vector embedding for the article's content. The search engine then combines traditional keyword matching with this semantic (vector) search to find the most *conceptually relevant* results in your knowledge base.

* **Content Connections (Find Similar):** Every article features a "Find Similar" (🔗) button. This runs an instant vector similarity search to show you all other related articles you've saved, helping you discover hidden connections in your research.

* **Context-Grounded Chat (RAG):** Chat with your knowledge! The chat bot is powered by the LanguageModel API but with a crucial feature: a strict "jailbreak" prompt is used that **forces** the AI to answer *only* based on your saved articles and the recent chat history. It will refuse to answer general knowledge questions, proving it's grounded in *your* data.

* **Conversational Memory:** The chat bot remembers your last turn, allowing for natural, follow-up questions.

* **Markdown Article Viewer:** Click "View" on any article to open a clean, scrollable modal that renders the summary (with full markdown support using Showdown.js). You can also open this in a new, beautifully formatted "Reader View" tab.

* **Multi-Article Insights:** Select any two or more articles from your list, and a "Summarize" button will appear. Clicking this sends all selected summaries to the LanguageModel API to generate novel insights and identify common themes between them.

* **Advanced Notes & Rephrasing:** Add persistent personal notes to any article. Use the "Rephrase" button to have the AI polish your writing for clarity, right inside the notes modal.

* **Tag Management & Filtering:** Organize your knowledge with a complete tagging system. You can add/edit tags for any article and filter your entire library by one or more tags.

* **Insights Dashboard:** Click "Reading Insights" to see a dashboard of your activity, including total articles, articles saved this week, and a 7-day activity chart.

* **Full Data Portability:** You own your data. Export your entire knowledge base (articles, tags, notes) as a single JSON file, or import a previous backup.

## Tech Stack & Architecture

This is a 100% vanilla JavaScript project, built to be as lean and fast as possible with zero external dependencies (besides Showdown.js for markdown).

* **Manifest V3:** The modern, secure standard for Chrome Extensions.
* **Service Worker (`service-worker.js`):** The persistent background script that handles all saving, API calls, and message passing.
* **`chrome.storage.local`:** The database. Used in place of IndexedDB for simplicity and speed. Stores all articles, vectors, tags, and chat sessions.
* **Vanilla JS (ES6+):** All logic in the popup (`popup.js`), content script (`content.js`), and background is written in modern, dependency-free JavaScript.
* **Vanilla CSS3:** All styling (`popup.css`) is custom-written for this extension, with no frameworks.
* **BM25 Vectorization:** A custom, lightweight vectorization algorithm (`generateBM25Vector`) is built directly into `storage.js` to power the semantic search.

## Installation & Testing Instructions

**This extension requires a browser and system that supports Chrome's built-in AI (e.g., Chrome 141+ Dev/Canary on a compatible device).**

### Step 1: Enable On-Device AI Flags

1.  Open your compatible Chrome browser (e.g., Chrome Dev).
2.  Navigate to `chrome://flags`.
3.  Search for and **Enable** the following three flags:
    * `Enables optimization guide on device`
    * `Prompt API for Gemini Nano`
    * `Summarization API for Gemini Nano`
4.  After enabling all three, click the **"Relaunch"** button at the bottom of the screen.

### Step 2: Verify AI Model Download

This is a critical step. The AI model itself must be downloaded in the background.

1.  After relaunching, navigate to `chrome://components`.
2.  Look for the component named **"Optimization Guide On Device Model"**.
3.  **Check its Status:**
    * If the Status is **"Ready"** or **"Downloaded"**, you are all set.
    * If the Status is **"Update error"** or **"Not ready"**, click the **"Check for update"** button. This component is the Gemini Nano model, and it may take a few minutes to download. You may need to wait and check this page again until the status is "Ready".
    * *The extension will not work until this component is successfully downloaded.*

### Step 3: Load the Extension

1.  Download this repository as a ZIP file and unzip it to a folder on your computer.
2.  Open Chrome and navigate to `chrome://extensions`.
3.  Enable **"Developer mode"** in the top-right corner.
4.  Click the **"Load unpacked"** button.
5.  Select the unzipped folder (the one containing `manifest.json`).
6.  The "LocalFirst Knowledge Base" extension will appear. Pin it to your toolbar.

### Step 4: How to Test (Recommended Demo Flow)

1.  **Save 3-5 Articles:**
    * Visit a few different web articles (e.g., news, blogs, tech articles).
    * On each page, press **`Ctrl+Shift+S`** or save summary from menu that appears after right-clicking on the page. A "Saved!" notification will appear on-page.

2.  **View & Summarize:**
    * Open the extension popup. You will see your saved articles, each with an AI-generated summary.
    * Click the **"View"** button on any article to open the clean, scrollable markdown viewer.

3.  **Test Hybrid Search:**
    * In the search bar, type a *concept* that appears in one of your articles (e.g., "machine learning").
    * Notice that the most relevant articles appear, even if they don't contain that exact keyword in their title.

4.  **Test Content Connections:**
    * Click the **"🔗" (Find Similar)** button on an article.
    * The list will instantly refresh to show you *only* the most semantically similar articles from your knowledge base.

5.  **Test Grounded Chat:**
    * Click the **"💬 Chat with Knowledge"** button to open the chat view.
    * **Test the "Guardrail":** Ask a general knowledge question like, _"What is the first Call of Duty game?"_ The AI will correctly respond: _"I'm sorry, I couldn't find any relevant information in your knowledge base..."_ This proves it is grounded in your data.
    * **Test the Context:** Now, ask a question *about your articles*, like _"What did I save about AI?"_ The AI will read the context from your saved articles and provide a correct answer.
    * **Test the History:** Ask a follow-up question like, _"Tell me more about the first one you mentioned."_ The AI will correctly understand your follow-up based on the previous chat message.

## Future Work

This project is a powerful proof-of-concept for 100% local, on-device AI. The current features create a robust "second brain." The next steps would be to make that brain proactive, turning the tool into a true research assistant.

* **Proactive Knowledge Agent (The "Session" Idea):**
    This is the "Version 2.0" vision for the extension. Instead of passively waiting for the user to save, the extension would become an active assistant during a "research session." It would:
    * **Monitor Dwell Time:** Automatically flag and summarize paragraphs the user spends a significant time reading, assuming they are important.
    * **Detect Context Switching:** Notice when a user reads a paragraph, then opens a new tab to search for a term. It would then use the LanguageModel API to find connections between the original article and the new search page.
    * **Use an Event Queue:** These "events" (dwell time, context switch) would be pushed to a processing queue (the "stack") and handled by the service worker in the background, building a rich, interconnected knowledge graph without user friction.

* **Client-Side Encryption:**
    Implement the `Web Crypto API` to allow users to set a master password. This would encrypt the entire `chrome.storage.local` database, ensuring all saved articles and notes are unreadable to anyone but the user.

* **Browser History Integration:**
    As a key step toward the "Proactive Agent," this would add the `history` permission. This would allow the chat bot to find connections between your saved knowledge and your recent browsing patterns, answering questions like, "What was that article I was reading yesterday about 3D models?".

* **Proofreader API Integration:**
    Integrate the `Proofreader API` directly into the "Notes" modal. This would provide real-time grammar, style, and clarity suggestions for your personal notes, polishing your thoughts as you type them.
